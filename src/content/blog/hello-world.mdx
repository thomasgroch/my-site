## Code

Fenced code gets syntax highlighting that follows the site theme, light or dark:

```js
export function readingTime(body = '') {
  const words = body.split(/\s+/).filter(Boolean).length
  return Math.max(1, Math.ceil(words / 220))
}
```

Inline code like `npm run verify` works too.
