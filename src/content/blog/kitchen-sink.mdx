This is the opening paragraph. It is where the reader decides whether to stay, so it deserves the same size as the rest of the body, never smaller. A good paragraph sits between 60 and 75 characters per line, with enough line height that the eye finds the start of the next line without effort.

A second paragraph shows the rhythm between blocks. Text can be **bold**, *italic*, ***both***, ~~struck through~~, or `inline code`. Links look [like this](/blog), and external ones [like this](https://developer.mozilla.org/). HTML elements also work: <kbd>Cmd</kbd> + <kbd>K</kbd>, <mark>highlighted text</mark>, <abbr title="Cascading Style Sheets">CSS</abbr>, H<sub>2</sub>O and E = mc<sup>2</sup>.

## Code

Fenced code gets syntax highlighting that follows the site theme. The header shows the language and a copy button:

```ts
type Post = { title: string; words: number }

export function readingTime({ words }: Post): number {
  return Math.max(1, Math.ceil(words / 220))
}
```

With a file name, using `title="..."`:

```js title="src/lib/blog.js"
export const isVisible = ({ data }) => import.meta.env.DEV || !data.draft
```

Highlighted lines, using `{1,3-4}` after the language:

```css {1,3-4}
.post { font-size: clamp(1.0625rem, 0.9rem + 0.6vw, 1.25rem); }
.post-content { line-height: 1.65; }
.post-content p { font-weight: 400; }
.post { max-width: 34em; }
```

Or with a comment inside the code:

```js
const a = 1
const b = 2 // [!code highlight]
const c = 3
```

Added and removed lines, with `// [!code ++]` and `// [!code --]`:

```js
export default defineConfig({
  site: 'https://example.com', // [!code --]
  site: 'https://thomasdev.xyz', // [!code ++]
})
```

A long line, to check horizontal scroll:

```bash
npx astro build --verbose && node scripts/check-links.mjs --base https://thomasdev.xyz --timeout 30000
```

A `diff` block, colored by the grammar:

```diff
- .post-content { font-size: 1rem; }
+ .post-content { font-size: 1.1875rem; }
```

Plain text without a language:

```
No highlighting here.
```
