Most of what we ask a language model in production is not "write me an essay". It is "which of these three buckets does this ticket go into?". [SemIf](https://github.com/TheoLeeCJ/SemIf-OpenJev) is a small experiment around that question, and its browser demo runs the whole thing on your own GPU: no server, no API key, and nothing leaves the page.

This post is a trimmed-down version of that demo. In the next parts, the same model plays two games: it is the [audience in Show do Milhão](/blog/llm-show-do-milhao) and the [brain of a Pac-Man ghost](/blog/llm-pac-man-ghost).

## Two ways to ask 🎯 vs ✍️

Given a situation, a question and a list of options, there are two ways to get a choice out of the model:

- **🎯 Direct readout.** Label the options A, B, C, ask for one letter, and read the log-probabilities of those letter tokens from a single forward pass. A softmax over them gives a distribution. Nothing is actually generated.
- **✍️ Generation.** Ask the model to *write* a JSON object with a probability for each option, token by token, then parse it.

The first is one step. The second is dozens of steps, and the JSON can still come back malformed. Try both on the same input:

The two numbers don't have to agree. The direct readout is what the model's next token *would* be; the generated JSON is what the model *says* it believes. Neither is a calibrated probability.

## How the readout works

The core of the direct readout is one chat completion with a grammar that allows only the option letters, a strong bias toward those tokens, and `logprobs` turned on:

```js title="worker.js"
const response = await engine.createChatCompletion({
  messages: messagesFor(data, 'direct'),
  max_tokens: 1,
  logprobs: true,
  top_logprobs: 20,
  logit_bias: Object.fromEntries(labels.map((_, i) => [String(labelBase + i), 100])),
  grammar: `root ::= ${labels.map((label) => `"${label}"`).join(' | ')}`,
})
const probabilities = softmax(optionLogprobs(response, labels))
```

`labelBase` is the token id of `A` in each model's vocabulary, which is why every model entry carries it.
