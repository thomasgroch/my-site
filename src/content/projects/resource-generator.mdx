## O desafio

Criar um recurso novo em projetos PHP era sempre o mesmo trabalho: copiar uma estrutura repetitiva e ajustá-la para cada nome.

## O que foi feito

- Gera toda a estrutura de arquivos a partir do nome do recurso
- Uma entrada, vários arquivos prontos
- Código publicado no GitHub

## Meu papel

Projeto pessoal. Desenvolvi o gerador e o modelo de estrutura que ele cria.

## Resultado

Menos código repetitivo e mais tempo para o que cada projeto realmente pede.
