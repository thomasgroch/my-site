## O desafio

Subir e manter o OmniRoute dependia de passos manuais e de configurações que ficavam fora do repositório, o que torna difícil repetir o processo depois.

## O que foi feito

- Manifestos declarativos para rodar o OmniRoute no k3s
- Sincronização e reconciliação contínuas com Argo CD
- Estado do cluster versionado no Git

## Meu papel

Projeto pessoal open source. Escrevi a infraestrutura como código de ponta a ponta.

## Resultado

Um deploy que dá para reproduzir e auditar: o que muda no Git é aplicado no cluster.
