## O desafio

Quem trabalha como freelancer no Workana precisa ver os novos trabalhos logo que são publicados. Recarregar a plataforma o dia inteiro não é uma forma prática de fazer isso.

## O que foi feito

- Widget que acompanha os trabalhos mais recentes do Workana
- Interface leve, feita para ficar aberta ao lado do trabalho
- Código publicado no GitHub

## Meu papel

Projeto pessoal. Fiz a ideia, o código e a manutenção.

## Resultado

Uma ferramenta simples para um incômodo real de quem trabalha na plataforma.
